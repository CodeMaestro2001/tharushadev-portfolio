# Skill icon sources

These SVG files are served locally; the application does not request an external icon CDN.

- Technology logos: [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), MIT license (see DEVICON-LICENSE.txt). Original variants, except Django (plain) and AWS (original-wordmark).
- Celery, n8n, and OpenAI: [Simple Icons 13.21.0](https://github.com/simple-icons/simple-icons/tree/13.21.0/icons), CC0 (see SIMPLE-ICONS-LICENSE.txt).
- React Native shares the React logo; Spring Boot uses the Spring ecosystem logo.
- Machine Learning, Deep Learning, Computer Vision, and YOLO use illustrative Lucide symbols in the component, not brand logos.

SVG artwork is unmodified. Logos and brand names remain trademarks of their respective owners; inclusion identifies technologies, not endorsement.
